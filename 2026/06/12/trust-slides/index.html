Pass 流水线 · 7 阶段协作汇总

从 IR 到加固二进制的七步走

#Pass输入处理输出对应机制
P1UnsafetyMarkerIR + rustc metadata遍历 attrs，标记 unsafe/FFI/asm/inttoptrtainted source set机制 #7 (Layer 1)
P2SVFGBuilderLLVM IRAndersen 指向分析 + 构建 SVFG稀疏值流图机制 #6 (SVF)
P3TaintPropagatorSVFG + sourcesBFS 前向传播 + 4 规则 + budgettainted node set机制 #8 (Layer 2)
P4AllocRewritertainted set + IR__rust_alloc → _safe / _unsafe改写后 IR机制 #4 (双堆)
P5StackSplittertainted alloca + IRalloca 展开为 unsafe SP gep改写后 IR机制 #5 (双栈)
P6GateInserter跨域调用点插入 enter/exit 内联汇编含 gate 的 IR机制 #10/#11 (Gate)
P7WRPKRUScannerfinal binary扫描 0F 01 EF 字节模式 · 含跨指令边界pass / fail机制 #2 (WRPKRU)

🔒 协作不变量

Design Tradeoffs · 四旋钮 + 失效场景
设计权衡 · 精度 ↔ 性能

四个调节旋钮 + 四类失效场景

调节旋钮拧紧（高精度）拧松（低开销）影响
Context 敏感深度k = ∞k = 1调用链精度
Field 敏感性完全字段区分字段坍缩struct 精度
Working budget无限固定阈值编译时间
IntToPtr 处理全保守选择性放行指针算术覆盖
🚫 四类失效场景
  • 动态加载 .so：dlopen 编译期不可见 → 运行时保守标整库
  • JIT 生成代码：V8 / Lua / Wasm 运行时新增代码 → 不支持
  • rustc unsoundness：lifetime 扩张 bug → 攻击通过 safe 代码
  • Transmute / 复杂指针算术：触发保守标记 → 性能塌陷
✅ 论文核心原则

Soundness over precision：宁可误报，不能漏报。漏报 = 安全漏洞。任何被 untrusted 触及的对象都进 untrusted 域；SVF 不确定时一律保守；这是后续工作批评 "过度保守" 的根源，但也是 TRust 安全保证的基石。

Critique · 三大根本局限
批判性评价 · 来自 2024–2025 后续工作

范式局限的三大维度

CRITIQUE 01 · SandCell '25

边界刚性

  • safe/unsafe 二分不够灵活
  • 无法把两个独立 unsafe 库互相隔离
  • 一个 FFI 被攻破 → 全部 unsafe 数据暴露
  • 不支持执行实例隔离（per-request sandbox）
  • 并发请求共享同一 untrusted 运行时
CRITIQUE 02 · SandCell '25

TCB 庞大

  • 整个 std + rustc 进 TCB
  • rustc soundness bug 可绕过
  • std 内 unsafe 漏洞不受保护
  • TCB ≈ 数百万行代码
  • 与"最小 TCB 原则"相悖
CRITIQUE 03 · Friend-or-Foe

无故障恢复

  • 违规即崩溃
  • 缺少 SDRaD 的 rewind 能力
  • 长服务不友好
  • 单次违规 = 整服务下线
  • 与云原生韧性需求不匹配
📛 未公开薄弱点

SVF 不处指针算术 → 过度保守 · 工具链改造大（rustc fork）· 多线程模型不清晰 · 精度数据未公开 · LLVM 14 强耦合

📛 SafeFFI '25 范式批评

"事后遏制"vs"事前防御"——TRust 不阻止漏洞产生，仅阻止扩散；调试时仍需面对原始漏洞

Conclusion · 范式定位
结论 · 范式定位

TRust 没有补好 Rust 的安全裂缝

— 它从未声称要补好 —

但它给我们提供了一个清晰的工程框架：理解这条裂缝有多大 · 用什么工具去缓解 · 缓解的代价是什么 · 还有哪些缝隙留给未来。

必读基线

12 个机制细节集大成 · MPK + SVF + 双堆双栈 + Gate · 工程完整度最高

必须超越的局部最优

"safe/unsafe 二分 + MPK"范式的极值点 · 突破来自跳出此范式

值得致敬

明确的威胁模型 · 完整的实现 · 诚实的局限承认 · 优秀的系统安全研究范式

🔮 下一代研究的 5 条路径

① 跨 ISA 重做（ARM MTE/CHERI Morello）· ② 边界自动派生（用 RustBelt 形式化结果）· ③ 故障恢复集成（融合 SDRaD rewind）· ④ 多沙箱模型（突破 16 域上限）· ⑤ 隔离 + 净化融合（边界净化 + 后端隔离）
